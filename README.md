# 🌤️ Weather API Project

A responsive weather application that allows users to search for a city and view its current weather information using a Weather API.

## 🚀 Live Demo

👉 **[View Live Weather App]([YOUR_DEPLOYMENT_LINK_HERE](https://current-weather-check18.netlify.app))**

## 📌 Features

- 🔍 Search weather by city name
- 🌡️ Display current temperature
- 💧 Show humidity
- 💨 Show wind speed
- 🌤️ Display weather conditions
- 📱 Responsive design
- ⚡ Fetches real-time weather data using an API
- ❌ Handles invalid city/search errors

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather API
- REST API
- Fetch API

## ⚙️ How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Ansh-Ks18/Weather-api-project.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Search for a city to view its weather information.

## 🔑 API Configuration

This project uses a weather API to retrieve real-time weather information.

If the API requires an API key, add your key to the appropriate configuration in the JavaScript file.

**Do not upload your private API key to GitHub.**
